# Code of conduct

AdobeWine follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and patient, assume good faith, criticise ideas rather than
people, and keep discussions on topic. Harassment, insults and personal attacks are not
accepted. Report problems to the maintainers through GitHub (private message or a
private security advisory for sensitive matters); reports are handled confidentially.
